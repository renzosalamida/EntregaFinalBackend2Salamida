# Entrega Final - Backend Coderhouse

## Alumno

Renzo Salamida

## Descripción

Proyecto final del curso de Backend desarrollado con Node.js, Express y MongoDB.

El proyecto permite administrar productos y carritos mediante una API REST y cuenta con vistas realizadas en Handlebars.

## Tecnologías utilizadas

- Node.js
- Express
- MongoDB
- Mongoose
- Express Handlebars
- Socket.IO

## Ejecutar el proyecto

```bash
npm run start
```

Servidor:

```
http://localhost:8080
```

## Funcionalidades

- CRUD de productos.
- CRUD de carritos.
- Persistencia con MongoDB.
- Filtros, paginación y ordenamiento de productos.
- Populate de productos en el carrito.
- Vistas con Handlebars para productos y carritos.
